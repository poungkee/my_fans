### 5. Docker Compose로 로컬 환경 실행

**가장 간단한 방법** - 모든 서비스를 한 번에 실행:

```bash
# 프로젝트 루트로 이동
cd D:/dev1

# Docker Compose로 모든 서비스 실행
docker-compose up -d

# 실행되는 서비스:
# - PostgreSQL (5432)
# - Redis (6379)
# - Main API (3000)
# - API Crawler (4003)
# - Scheduler
# - Summarize AI (8000)
# - Bias Analysis AI (8002)
# - Classification API (5000)

# 로그 확인
docker-compose logs -f

# 서비스 중지
docker-compose down
```

**docker-compose.yml** 파일 확인:
```yaml
version: '3.8'

services:
  postgres:
    image: postgres:15
    environment:
      POSTGRES_DB: fans_db
      POSTGRES_USER: fans_admin
      POSTGRES_PASSWORD: your_password
    ports:
      - "5432:5432"
    volumes:
      - postgres_data:/var/lib/postgresql/data

  redis:
    image: redis:7-alpine
    ports:
      - "6379:6379"

  main-api:
    build: ./backend/fans_main_api
    ports:
      - "3000:3000"
    depends_on:
      - postgres
      - redis
    environment:
      DB_HOST: postgres
      REDIS_HOST: redis

  # ... 기타 서비스들
```

## AWS 환경 구성

### 1. AWS 계정 설정

#### AWS 계정 생성
1. https://aws.amazon.com 접속
2. "Create an AWS Account" 클릭
3. 이메일, 비밀번호, 결제 정보 입력
4. 전화번호 인증

#### IAM 사용자 생성 (권장)

```bash
# AWS 콘솔에서:
# 1. IAM 서비스 접속
# 2. Users > Add user
# 3. User name: fans-deploy
# 4. Access type: Programmatic access
# 5. Permissions: Administrator Access (또는 최소 권한)
# 6. Create user
# 7. Access Key ID와 Secret Access Key 저장
```

#### AWS CLI 인증 설정

```bash
# AWS 인증 구성
aws configure

# 입력 필요:
AWS Access Key ID: AKIA... (IAM 사용자 Access Key)
AWS Secret Access Key: ... (IAM 사용자 Secret Key)
Default region name: ap-northeast-2 (서울 리전)
Default output format: json

# 인증 확인
aws sts get-caller-identity
```

### 2. ECR (Container Registry) 생성

```bash
# ECR 레지스트리 생성 스크립트
aws ecr create-repository --repository-name fans/frontend --region ap-northeast-2
aws ecr create-repository --repository-name fans/main-api --region ap-northeast-2
aws ecr create-repository --repository-name fans/api-crawler --region ap-northeast-2
aws ecr create-repository --repository-name fans/scheduler --region ap-northeast-2
aws ecr create-repository --repository-name fans/summarize-ai --region ap-northeast-2
aws ecr create-repository --repository-name fans/bias-analysis-ai --region ap-northeast-2
aws ecr create-repository --repository-name fans/classification-api --region ap-northeast-2

# ECR 로그인
aws ecr get-login-password --region ap-northeast-2 | docker login --username AWS --password-stdin [YOUR_ACCOUNT_ID].dkr.ecr.ap-northeast-2.amazonaws.com
```

### 3. Terraform 변수 파일 생성

**파일 위치**: `D:\dev1\infra\terraform\secret.tfvars`

```hcl
# AWS 리전
aws_region = "ap-northeast-2"

# 프로젝트 정보
project_name = "FANS"
environment = "production"

# RDS 데이터베이스 설정
db_username = "fans_admin"
db_password = "YourSecurePassword123!"  # 강력한 비밀번호로 변경!
db_name = "fans_db"

# (선택사항) 도메인
domain_name = "fans.ai.kr"  # 없으면 주석 처리
```

⚠️ **주의**: `secret.tfvars` 파일은 절대 Git에 커밋하지 마세요!

`.gitignore`에 추가:

```bash
# 접속 확인
docker exec -it fans-postgres psql -U fans_admin -d fans_db
```

#### 스키마 생성

```sql
-- TypeORM이 자동으로 테이블을 생성하지만,
-- 수동으로 생성하려면:

-- Users 테이블
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    name VARCHAR(100),
    provider VARCHAR(50),
    provider_id VARCHAR(255),
    profile_image TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- News Articles 테이블
CREATE TABLE news_articles (
    id SERIAL PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT,
    summary TEXT,
    url TEXT UNIQUE NOT NULL,
    source VARCHAR(100),
    category VARCHAR(50),
    keywords TEXT[],
    bias_score DECIMAL(3, 2),
    political_leaning VARCHAR(20),
    image_url TEXT,
    published_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);

-- 인덱스 생성
CREATE INDEX idx_category ON news_articles(category);
CREATE INDEX idx_published_at ON news_articles(published_at DESC);
CREATE INDEX idx_keywords ON news_articles USING GIN(keywords);
```

## 문제 해결

### 문제 1: Node.js 버전 충돌

**증상**:
```
Error: The engine "node" is incompatible with this module
```

**해결**:
```bash
# nvm 설치 (Node Version Manager)
# Windows: https://github.com/coreybutler/nvm-windows
# macOS/Linux: https://github.com/nvm-sh/nvm

# Node.js 18 설치
nvm install 18
nvm use 18
```

### 문제 2: Python 패키지 설치 실패

**증상**:
```
ERROR: Could not build wheels for xxx
```

**해결**:
```bash
# Windows: Visual C++ Build Tools 설치 필요
# https://visualstudio.microsoft.com/downloads/

# macOS: Xcode Command Line Tools
xcode-select --install

# Ubuntu/Debian: build-essential 설치
sudo apt install build-essential python3-dev
```

### 문제 3: Docker 권한 에러

**증상 (Linux)**:
```
Got permission denied while trying to connect to the Docker daemon socket
```

**해결**:
```bash
# 사용자를 docker 그룹에 추가
sudo usermod -aG docker $USER

# 재로그인 또는
newgrp docker
```

### 문제 4: PostgreSQL 접속 실패

**증상**:
```
FATAL: password authentication failed
```

**해결**:
```bash
# Docker PostgreSQL 재시작
docker restart fans-postgres

# 비밀번호 확인
docker exec -it fans-postgres psql -U fans_admin -d fans_db

# 또는 환경 변수 확인
echo $DB_PASSWORD
```

### 문제 5: PORT 이미 사용 중

**증상**:
```
Error: listen EADDRINUSE: address already in use :::3000
```

**해결**:
```bash
# Windows
netstat -ano | findstr :3000
taskkill /PID [PID번호] /F

# macOS/Linux
lsof -ti:3000 | xargs kill -9
```

### 문제 6: AWS CLI 인증 실패

**증상**:
```
An error occurred (UnauthorizedOperation)
```

**해결**:
```bash
# AWS 인증 정보 재설정
aws configure

# 인증 확인
aws sts get-caller-identity

# 리전 확인
aws configure get region
```
