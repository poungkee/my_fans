## 프로젝트 개요

### FANS란?

FANS (Financial & Analytics News Service)는 **AI 기반 뉴스 큐레이션 및 편향성 분석 플랫폼**입니다.

### 핵심 가치

- **자동화**: 3분마다 최신 뉴스 자동 수집
- **AI 분석**: T5 기반 요약 + KoBERT 기반 편향 분석
- **객관성**: 뉴스 편향성을 수치화하여 제공
- **실시간**: Redis 캐싱으로 빠른 응답 (<100ms)
- **확장성**: 마이크로서비스 아키텍처로 독립적 확장 가능

### 프로젝트 배경

- **문제점**: 뉴스 매체별 편향성 심화, 객관적 정보 습득 어려움
- **해결책**: AI 기반 자동 분석 및 편향성 시각화
- **목표**: 사용자에게 객관적인 뉴스 소비 환경 제공

## 주요 기능

### 1. 뉴스 크롤링 및 수집

**자동 크롤링**:
- **주기**: 3분마다 자동 실행
- **소스**: Daum News, Naver News
- **카테고리**: 정치, 경제, 사회, 세계, IT/과학, 생활/문화, 스포츠, 연예
- **수집량**:
  - 시간당 약 800개
  - 일일 약 19,200개 (중복 제거 후 ~5,000개)

**크롤링 프로세스**:
```
1. Daum News 섹션 페이지 접속
2. 기사 목록 추출 (제목, URL, 이미지)
3. 각 기사 상세 페이지 접속
4. 본문, 언론사, 기자, 발행일 파싱
5. raw_news_articles 테이블에 저장
```

### 2. AI 자동 분석

**처리 파이프라인** (10분마다):
```
raw_news_articles (원본)
    ↓
[1] 분류 API
    - 카테고리 분류 (정치, 경제 등)
    - 언론사 매핑 (15개 언론사)
    ↓
[2] 요약 AI
    - T5 모델 기반 3문장 요약
    - 최대 100자
    ↓
[3] 키워드 추출
    - KoNLPy 형태소 분석
    - 빈도 기반 상위 10개
    ↓
[4] 편향성 분석
    - 감성 분석 (긍정/부정/중립)
    - 정치 성향 분석
    - 편향 점수 (-1.0 ~ +1.0)
    ↓
news_articles (최종)
```

### 3. 뉴스 피드 제공

**기능**:
- 카테고리별 뉴스 조회
- 최신순 / 인기순 정렬
- 페이지네이션 (20개/페이지)
- 전문 검색 (Full-Text Search)
- Redis 캐싱 (응답 시간 <100ms)

**API 엔드포인트**:
```
GET /api/news/feed?topics=정치,경제&limit=60&sort=latest
GET /api/news/:id
GET /api/news/search?q=검색어
```

### 4. 편향성 시각화

**제공 정보**:
- **편향 점수**: -1.0 (좌편향) ~ +1.0 (우편향)
- **감성**: 긍정/부정/중립 (신뢰도 포함)
- **정치 성향**: 진보/중도/보수
- **언론사 편향도**: 언론사별 평균 편향 점수

**시각화**:
- 편향 스펙트럼 바 차트
- 감성 분석 원 차트
- 언론사별 비교 그래프

### 5. 소셜 로그인

**지원 플랫폼**:
- 카카오 OAuth 2.0
- 네이버 OAuth 2.0
- 일반 로그인 (이메일/비밀번호)

**계정 연동**:
- 소셜 계정 ↔ 일반 계정 연동
- 같은 이메일 자동 감지
- 비밀번호 확인 후 병합

### 6. 개인화 추천 (선택적)

**추천 알고리즘**:
- Collaborative Filtering (협업 필터링)
- Content-Based Filtering (콘텐츠 기반)
- Keyword-Based (키워드 기반)
- Bias-Based (편향 성향 기반)
- Trending (실시간 인기)

**가중치**:
```
협업 필터링: 25%
콘텐츠 기반: 20%
키워드 기반: 30%
편향 성향: 15%
인기 뉴스: 10%
```

### 7. 사용자 활동 추적

**추적 항목**:
- **조회 (VIEW)**: 기사 열람
- **좋아요 (LIKE)**: 기사 선호
- **싫어요 (DISLIKE)**: 기사 비선호
- **북마크 (BOOKMARK)**: 저장

**수집 데이터**:
- 읽은 시간 (초)
- 읽은 비율 (%)
- 클릭 시간
- 스크롤 깊이

## 확장성

### 수평 확장 (Horizontal Scaling)

**확장 가능 서비스**:
- Frontend: 트래픽 증가 시 레플리카 추가
- Main API: 부하 분산
- AI Services: GPU 인스턴스 추가
- Crawler: 병렬 크롤링 인스턴스 증가

### 수직 확장 (Vertical Scaling)

**확장 가능 리소스**:
- RDS: 인스턴스 타입 업그레이드
- Redis: 메모리 증설
- AI 서비스: GPU 추가
