## 환경별 개요

### 지원 환경

| 환경 | 용도 | 컨테이너 | DB | 도메인 |
|------|------|---------|-----|--------|
| **Local** | 로컬 개발 | Docker Compose | PostgreSQL (컨테이너) | localhost |
| **ECS** | AWS 프로덕션 | ECS Tasks | RDS PostgreSQL | fans.ai.kr |
| **EKS** | Kubernetes 프로덕션 | K8s Pods | RDS PostgreSQL | fans.ai.kr |

### 환경별 주요 차이점

| 항목 | Local | ECS | EKS |
|------|-------|-----|-----|
| **DB 연결** | `postgres` (컨테이너명) | RDS 엔드포인트 | RDS 엔드포인트 |
| **서비스 간 통신** | Docker 네트워크 | Service Discovery | K8s Service DNS |
| **환경변수 관리** | `.env.local` | Secrets Manager | K8s Secrets |
| **OAuth Callback** | `localhost:3000/...` | `api.fans.ai.kr/...` | `api.fans.ai.kr/...` |
| **이미지 저장소** | 로컬 빌드 | ECR | ECR |

### 6. ECS Task Definition 생성

**`ecs-task-definition.tf` 예시**:

```hcl
# Main API Task Definition
resource "aws_ecs_task_definition" "main_api" {
  family                   = "fans-main-api"
  requires_compatibilities = ["FARGATE"]
  network_mode             = "awsvpc"
  cpu                      = 512
  memory                   = 1024
  execution_role_arn       = aws_iam_role.ecs_execution_role.arn
  task_role_arn            = aws_iam_role.ecs_task_role.arn

  container_definitions = jsonencode([
    {
      name  = "main-api"
      image = "${aws_ecr_repository.fans.repository_url}:latest"
      essential = true

      portMappings = [
        {
          containerPort = 3000
          protocol      = "tcp"
        }
      ]

      environment = [
        { name = "NODE_ENV", value = "production" },
        { name = "PORT", value = "3000" },
        { name = "DB_HOST", value = aws_db_instance.main.address },
        { name = "DB_PORT", value = "5432" },
        { name = "DB_NAME", value = "fans_db" },
        { name = "DB_USERNAME", value = "fans_user" }
      ]

      secrets = [
        {
          name      = "DB_PASSWORD"
          valueFrom = aws_secretsmanager_secret.db_password.arn
        },
        {
          name      = "JWT_SECRET"
          valueFrom = aws_secretsmanager_secret.jwt_secret.arn
        },
        {
          name      = "SESSION_SECRET"
          valueFrom = aws_secretsmanager_secret.session_secret.arn
        }
      ]

      logConfiguration = {
        logDriver = "awslogs"
        options = {
          awslogs-group         = "/ecs/fans-main-api"
          awslogs-region        = "ap-northeast-2"
          awslogs-stream-prefix = "ecs"
        }
      }
    }
  ])
}
```

### 7. ECS Service 생성

```hcl
# Main API Service
resource "aws_ecs_service" "main_api" {
  name            = "fans-main-api"
  cluster         = aws_ecs_cluster.main.id
  task_definition = aws_ecs_task_definition.main_api.arn
  desired_count   = 2
  launch_type     = "FARGATE"

  network_configuration {
    subnets          = [aws_subnet.private_a.id, aws_subnet.private_b.id]
    security_groups  = [aws_security_group.ecs_tasks.id]
    assign_public_ip = false
  }

  load_balancer {
    target_group_arn = aws_lb_target_group.main_api.arn
    container_name   = "main-api"
    container_port   = 3000
  }

  service_registries {
    registry_arn = aws_service_discovery_service.main_api.arn
  }

  depends_on = [aws_lb_listener.https]
}
```

### 각 서비스별 Dockerfile 역할

#### Main API Dockerfile

```dockerfile
# Stage 1: Build

```

**역할**:
- TypeScript → JavaScript 컴파일
- 프로덕션 의존성만 포함 (경량화)
- Multi-stage build로 이미지 크기 축소

## 트러블슈팅

### 문제 1: PostgreSQL 연결 실패

**증상**:
```
Error: connect ECONNREFUSED 127.0.0.1:5432
```

**원인**: DB_HOST 설정 오류

**해결**:
```bash
# 로컬 환경
DB_HOST=postgres  # Docker Compose 서비스명

# ECS/EKS 환경
DB_HOST=<실제-RDS-엔드포인트>

# 연결 테스트
docker exec -it fans_postgres psql -U fans_user -d fans_db
```

### 문제 2: AI 서비스 통신 실패

**증상**:
```
Error: getaddrinfo ENOTFOUND summarize-ai
```

**원인**: 서비스 간 네트워크 설정 오류

**해결**:
```bash
# 로컬: Docker Compose 네트워크 확인
docker network ls
docker network inspect fans_network

# ECS: Service Discovery 확인
aws servicediscovery list-services

# EKS: Service DNS 확인
kubectl get services -n fans-svc
```

### 문제 3: 환경변수 로드 안됨

**증상**:
```
undefined environment variable
```

**해결**:
```bash
# 환경 파일 확인
cat .env

# 환경 전환
./scripts/switch-env.sh local

# Docker Compose 재시작
docker-compose down
docker-compose up -d
```

### 문제 4: OAuth 리다이렉트 실패

**증상**:
```
redirect_uri_mismatch
```

**해결**:
1. 카카오/네이버 콘솔에서 Redirect URI 등록 확인
2. `.env` 파일의 `KAKAO_REDIRECT_URI` 확인
3. HTTPS 사용 중인지 확인 (프로덕션)
