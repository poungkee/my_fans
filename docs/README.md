# FANS 프로젝트 문서 가이드

> 팀원들과 공유하기 위한 FANS (Fake news Analysis and News Service) 프로젝트의 핵심 문서 모음입니다.

## 📚 핵심 문서 목록

### 1️⃣ [프로젝트 시작 가이드](./01_프로젝트_시작가이드.md)
**프로젝트를 처음 접하는 신규 팀원을 위한 필수 문서**

- 프로젝트 소개 및 목적
- 시스템 아키텍처 다이어그램
- 9개 마이크로서비스 구성 및 역할
- 사용 기술 스택 (Node.js, Python, PostgreSQL, Redis, Docker)
- 로컬 환경 설정 및 실행 방법
- 주요 구현 기능 목록

**👥 대상**: 신규 팀원, 프로젝트 관계자, 기술 검토자

---

### 2️⃣ [시스템 아키텍처](./02_시스템_아키텍처.md)
**전체 시스템 설계 및 데이터베이스 구조를 이해하기 위한 문서**

- 전체 시스템 아키텍처 다이어그램
- 15개 테이블 상세 ERD 및 설명
- 테이블별 컬럼 구조 및 타입
- 인덱스 설계 및 최적화
- 트리거 및 함수 정의
- 서비스 간 통신 및 데이터 흐름
- 뉴스 크롤링 및 AI 분석 파이프라인

**👥 대상**: 백엔드 개발자, DB 관리자, 아키텍트

---

### 3️⃣ [운영 및 배포 가이드](./03_운영_및_배포_가이드.md)
**로컬/AWS 환경에서 시스템을 배포하고 운영하기 위한 실무 가이드**

- **로컬 환경 설정**
  - Docker Compose 기반 실행
  - 환경 변수 설정 (.env.local)
  - 트러블슈팅

- **AWS 배포**
  - ECS 배포 가이드
  - EKS 배포 가이드
  - Terraform 인프라 구성
  - CI/CD 파이프라인 (GitHub Actions)

- **모니터링 및 운영**
  - Prometheus + Grafana
  - CloudWatch Logs
  - 알림 설정

**👥 대상**: DevOps 엔지니어, 시스템 관리자, 백엔드 개발자

---

### 4️⃣ [배포 전략 가이드](./04_배포_전략_가이드.md)
**무중단 배포 전략 및 환경별 배포 방법론**

- Rolling Update vs Canary vs Blue/Green 비교
- ECS 배포 전략
- EKS 배포 전략 (Kubernetes)
- 서비스 구현 현황 및 체크리스트
- 배포 롤백 절차

**👥 대상**: DevOps 엔지니어, 시스템 아키텍트

### 5️⃣ [성능 최적화 가이드](./05_성능_최적화_가이드.md)
**시스템 성능 개선 및 모니터링 기법**

- 데이터베이스 쿼리 최적화
- 인덱스 전략 및 파티셔닝
- 캐싱 전략 (Redis)
- API 성능 최적화
- AI 모델 추론 성능 개선
- 성능 모니터링 도구 및 지표

**👥 대상**: 백엔드 개발자, DBA, 성능 엔지니어

### 6️⃣ [보안 가이드](./06_보안_가이드.md)
**시스템 보안 강화 및 취약점 대응 방안**

- AWS 보안 설정 (IAM, Security Group, WAF)
- 데이터베이스 보안 (암호화, 접근 제어)
- API 보안 (인증/인가, Rate Limiting)
- 컨테이너 보안 (이미지 스캔, 런타임 보안)
- 시크릿 관리 (AWS Secrets Manager)
- 보안 모니터링 및 감사 로그

**👥 대상**: 보안 담당자, DevOps 엔지니어, 백엔드 개발자

---

### 7️⃣ [비용 최적화 및 스케일링 가이드](./07_비용_최적화_및_스케일링_가이드.md)
**클라우드 비용 절감 및 오토스케일링 전략**

- AWS 비용 분석 (ECS vs EKS)
- 리소스 최적화 전략
- 오토스케일링 설정
  - Horizontal Pod Autoscaler (HPA)
  - KEDA (Kubernetes Event Driven Autoscaler)
  - Karpenter (노드 자동 확장)
- 비용 모니터링 및 알림

**👥 대상**: DevOps 엔지니어, 클라우드 아키텍트, 관리자

---

### 8️⃣ [장애 대응 가이드](./08_장애_대응_가이드.md)
