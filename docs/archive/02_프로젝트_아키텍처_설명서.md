## 프로젝트 개요

### FANS란?

**FANS (Financial & Analytics News Service)**는 AI 기반으로 뉴스를 자동 수집하고 분석하여 사용자에게 객관적인 정보를 제공하는 웹 서비스입니다.

### 핵심 가치

- **자동화**: 30초마다 최신 뉴스 자동 수집
- **AI 분석**: GPT 기반 요약 + BERT 기반 편향 분석
- **객관성**: 뉴스 편향성을 수치화하여 제공
- **실시간**: Redis 캐싱으로 빠른 응답 (<100ms)

### 주요 기능

1. **자동 뉴스 수집**: Naver News API를 통한 실시간 크롤링
2. **AI 자동 분류**: 머신러닝 기반 카테고리 자동 분류
3. **뉴스 요약**: OpenAI GPT를 활용한 3문장 요약
4. **편향 분석**: BERT 모델로 좌/우 편향 점수 계산
5. **키워드 추출**: 핵심 키워드 자동 추출
6. **사용자 맞춤 추천**: 하이브리드 추천 알고리즘

```python
def summarize_news(content):
    prompt = f"""
    다음 뉴스 기사를 3문장으로 요약해주세요:
    - 핵심 내용 위주로
    - 객관적인 톤 유지
    - 한국어로 작성

    기사: {content}
    """
    response = openai.ChatCompletion.create(
        model="gpt-3.5-turbo",
        messages=[{"role": "user", "content": prompt}]
    )
    return response.choices[0].message.content
```

**편향 분석 알고리즘**:
```python
def analyze_bias(text):
    # BERT 기반 편향 분류
    inputs = tokenizer(text, return_tensors="pt", truncation=True)
    outputs = model(**inputs)

    # 좌편향/중립/우편향 점수 계산
    scores = torch.softmax(outputs.logits, dim=1)

    return {
        'left_bias': scores[0][0].item(),
        'neutral': scores[0][1].item(),
        'right_bias': scores[0][2].item(),
        'bias_score': scores[0][2].item() - scores[0][0].item()  # -1 ~ +1
    }
```

## 서비스 흐름도

### 1. 뉴스 수집 및 처리 Flow

```
[1] ⏰ Scheduler (30초마다)
      │
      ▼
[2] 🕷️ API Crawler
      │ - Naver News API 호출
      │ - 검색어: "정치", "경제", "사회", "기술" 등
      │ - 페이지: 1-3 (약 30개 기사)
      ▼
[3] 💾 raw_news_data 테이블에 저장
      │ - title, content, url, published_at
      │ - source (언론사)
      ▼
[4] 📊 Classification API 호출
      │ - 카테고리 자동 분류
      │ - 키워드 추출
      ▼
[5] 💾 news_articles 테이블에 저장
      │ - category, keywords 포함
      ▼
[6] 🤖 AI 처리 (병렬 실행)
      ├─────────────────────┬─────────────────────┐
      ▼                     ▼                     ▼
[7a] Summarize AI     [7b] Bias Analysis    [7c] Keyword 추출
      │ - GPT 3문장 요약    │ - BERT 편향 분석     │ - TF-IDF
      ▼                     ▼                     ▼
[8] 💾 news_articles 업데이트
      │ - summary 컬럼
      │ - bias_score, political_leaning 컬럼
      │ - keywords 컬럼
      ▼
[9] 📦 Redis 캐싱
      - 인기 뉴스 (24시간)
      - 최신 뉴스 (1시간)
      - 카테고리별 뉴스 (30분)
```

**처리 시간**:
- 크롤링: ~2초
- 분류: ~1초
- 요약: ~3초 (GPT API)
- 편향 분석: ~2초 (BERT)
- **총 처리 시간**: ~8초/기사

**일일 처리량**:
- 30초마다 30개 = 2분당 30개
- 1시간: 900개
- 24시간: **21,600개** (중복 제거 후 ~5,000개)

### 주요 테이블 상세

#### 1. users

```sql
CREATE TABLE users (
    id SERIAL PRIMARY KEY,
    email VARCHAR(255) UNIQUE NOT NULL,
    name VARCHAR(100),
    provider VARCHAR(50),  -- 'google', 'kakao', 'naver', 'local'
    provider_id VARCHAR(255),
    profile_image TEXT,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

#### 2. news_articles

```sql
CREATE TABLE news_articles (
    id SERIAL PRIMARY KEY,
    title TEXT NOT NULL,
    content TEXT,
    summary TEXT,                    -- AI 생성 요약
    url TEXT UNIQUE NOT NULL,
    source VARCHAR(100),             -- 언론사
    category VARCHAR(50),            -- 정치, 경제, 사회, 기술 등
    keywords TEXT[],                 -- 키워드 배열
    bias_score DECIMAL(3, 2),        -- -1.00 ~ +1.00
    political_leaning VARCHAR(20),   -- 'left', 'neutral', 'right'
    image_url TEXT,
    published_at TIMESTAMP,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    updated_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,

    -- 인덱스
    INDEX idx_category (category),
    INDEX idx_published_at (published_at DESC),
    INDEX idx_keywords USING GIN(keywords)
);
```

#### 3. user_read_history

```sql
CREATE TABLE user_read_history (
    id SERIAL PRIMARY KEY,
    user_id INT REFERENCES users(id) ON DELETE CASCADE,
    article_id INT REFERENCES news_articles(id) ON DELETE CASCADE,
    read_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    read_time INT,                   -- 체류 시간 (초)
    liked BOOLEAN DEFAULT FALSE,

    -- 인덱스
    INDEX idx_user_id (user_id),
    INDEX idx_article_id (article_id),
    INDEX idx_read_at (read_at DESC),
    UNIQUE(user_id, article_id)      -- 중복 방지
);
```

#### 4. raw_news_data

```sql
CREATE TABLE raw_news_data (
    id SERIAL PRIMARY KEY,
    title TEXT,
    content TEXT,
    url TEXT UNIQUE,
    source VARCHAR(100),
    published_at TIMESTAMP,
    crawled_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
    processed BOOLEAN DEFAULT FALSE,

    INDEX idx_processed (processed),
    INDEX idx_crawled_at (crawled_at DESC)
);
```

```sql
-- Full-Text Search
SELECT * FROM news_articles
WHERE
  to_tsvector('korean', title || ' ' || content)
  @@ to_tsquery('korean', '검색어')
ORDER BY published_at DESC
LIMIT 20;
```

**인덱스**:
```sql
CREATE INDEX idx_fts ON news_articles
USING GIN(to_tsvector('korean', title || ' ' || content));
```
