# FANS 뉴스 큐레이션 플랫폼 - 기술 문서

## 📋 프로젝트 개요

**FANS (Fact-checked AI News Service)**는 AI 기반 뉴스 큐레이션 및 편향성 분석 플랫폼입니다.

- **개발 기간**: 2025년 9월 ~ 10월
- **팀 구성**: 협업 프로젝트
- **목표**: 신뢰할 수 있는 뉴스 제공 및 편향성 분석

## 🔧 기술 스택

### Frontend
- **언어**: JavaScript (React 18)
- **UI 라이브러리**:
  - React Router DOM (페이지 라우팅)
  - Axios (HTTP 클라이언트)
  - CSS3 (스타일링)
- **빌드**: Node.js 18

### Backend API
- **언어**: TypeScript 5.9
- **프레임워크**: Express.js 4.21
- **ORM**: TypeORM 0.3
- **인증**:
  - JWT (JSON Web Token)
  - Session (express-session)
  - bcrypt (비밀번호 해싱)

### Database
- **주 데이터베이스**: PostgreSQL 15
- **캐싱**: Redis 7 (세션 저장소)

### AI/ML 서비스
1. **요약 AI** (Python FastAPI)
   - 모델: `eenzeenee/t5-base-korean-summarization`
   - 프레임워크: Transformers (Hugging Face)

2. **편향 분석 AI** (Python FastAPI)
   - KoBERT 기반 감성 분석
   - KoNLPy 키워드 추출
   - 정치 성향 분석

3. **카테고리 분류 AI** (Python Flask)
   - scikit-learn Random Forest
   - TF-IDF 벡터화

### 크롤링
- **API Crawler**: Axios + Cheerio (Node.js)
- **소스**: Daum News (8개 카테고리)
- **인코딩 처리**: iconv-lite (EUC-KR 지원)

### OAuth 인증
- **카카오 로그인**: Kakao OAuth 2.0
- **네이버 로그인**: Naver OAuth 2.0

### DevOps
- **컨테이너**: Docker + Docker Compose
- **서비스 구성**: 12개 컨테이너
- **스케줄러**: node-cron

## 📊 뉴스 크롤링 상세

### 크롤링 주기 및 설정

| 항목 | 설정값 | 설명 |
|------|--------|------|
| **자동 실행** | `AUTO_CRAWL=true` | 서버 시작 시 자동 크롤링 활성화 |
| **크롤링 주기** | **3분 (180초)** | `CRAWL_INTERVAL=180000` ms |
| **카테고리당 수집** | **5개 기사** | `CRAWL_LIMIT_PER_CATEGORY=5` |
| **총 카테고리** | **8개** | 정치, 경제, 사회, 세계, IT/과학, 생활/문화, 스포츠, 연예 |

### 수집량 계산

#### 시간당 수집량
- 3분마다 실행 = 시간당 **20회 실행**
- 카테고리당 5개 × 8개 카테고리 = **40개/회**
- **시간당 총 수집량**: 20회 × 40개 = **800개**

#### 일일 수집량
- **하루 수집량**: 800개/시간 × 24시간 = **19,200개**

### 크롤링 소스

#### 뉴스 출처
- **플랫폼**: Daum News (https://news.daum.net)
- **방식**: HTML 파싱 (Cheerio)
- **신뢰성**: ✅ 공식 뉴스 포털, 언론사 검증된 기사만 수집

#### 카테고리별 URL
```
정치:      https://news.daum.net/politics
경제:      https://news.daum.net/economy
사회:      https://news.daum.net/society
세계:      https://news.daum.net/world
IT/과학:   https://news.daum.net/tech
생활/문화: https://news.daum.net/culture
스포츠:    https://sports.daum.net
연예:      https://entertain.daum.net
```

### 크롤링 프로세스

#### 1단계: 원본 수집 (API Crawler)
```
[3분마다]
1. Daum News 섹션 페이지 접속
2. 기사 목록 추출 (제목, URL, 이미지)
3. 각 기사 상세 페이지 접속
4. 본문, 언론사, 기자, 발행일 파싱
5. raw_news_articles 테이블에 저장 (processed=false)

⏱️ 요청 간격:
- 기사 간: 1초 대기
- 카테고리 간: 2초 대기
```

#### 2단계: AI 처리 (Scheduler)
```
[10분마다]
1. Raw 뉴스 처리 (0분)
   - Random Forest로 카테고리 재분류
   - news_articles로 이동

2. AI 요약 생성 (1분 후)
   - T5 모델로 요약 생성
   - 최대 길이: 100자

3. 키워드 추출 (2분 후)
   - KoNLPy로 명사 추출
   - 빈도 기반 상위 10개

4. 편향 분석 (3분 후)
   - 감성 분석 (긍정/부정/중립)
   - 정치 성향 분석
```

### API 사용 한도

#### Naver Search API (뉴스 검색용)
- **일일 한도**: 25,000건/일
- **초당 요청**: 10건/초
- **현재 사용**: 로드밸런싱용 2개 키 보유
- **실제 사용량**: Daum 크롤링 위주, 검색 API는 보조

#### Daum News 크롤링
- **공식 한도**: 없음 (공개 웹페이지)
- **자체 제한**: 요청 간 1~2초 대기 (서버 부하 방지)
- **Robot.txt 준수**: ✅

### 신뢰성 보장

#### 중복 방지
```sql
-- URL 기반 중복 체크
SELECT * FROM raw_news_articles WHERE url = ?
SELECT * FROM news_articles WHERE url = ?

-- 이미 존재하면 스킵
```

#### 콘텐츠 검증
- **최소 길이**: 50자 이상
- **한글 비율**: 30% 이상
- **UI 키워드 필터링**: 광고, 로그인 등 제거
- **유효성 검사**: 실제 기사 콘텐츠만 저장

#### 인코딩 처리

```javascript
// EUC-KR, UTF-8 자동 감지 및 변환
```

## 🤖 AI 서비스 상세

### 1. 요약 AI (Summarize AI)

#### 기술 스택
- **언어**: Python 3.10
- **프레임워크**: FastAPI
- **모델**: `eenzeenee/t5-base-korean-summarization`
- **라이브러리**: Transformers (Hugging Face)

#### API 엔드포인트
```
POST /ai/summarize
{
  "text": "원본 기사 내용...",
  "max_length": 100
}

→ Response:
{
  "summary": "요약된 내용",
  "length": 45
}
```

#### 성능
- **요약 길이**: 최대 100자 (설정 가능)
- **처리 속도**: 평균 1~2초/기사
- **정확도**: T5 기반 한국어 특화 모델

### 2. 편향 분석 AI (Bias Analysis AI)

#### 기술 스택
- **언어**: Python 3.10
- **프레임워크**: FastAPI
- **모델**:
  - KoBERT (감성 분석)
  - KoNLPy (형태소 분석)

#### 분석 항목

##### 감성 분석
```
POST /analyze/sentiment
→ {
  "sentiment": "긍정/부정/중립",
  "confidence": 0.85,
  "score": 0.72,
  "positive_count": 15,
  "negative_count": 3
}
```

##### 키워드 추출
```
POST /analyze/keywords
→ {
  "keywords": [
    {"word": "경제", "score": 0.95},
    {"word": "성장", "score": 0.82}
  ]
}
```

##### 정치 성향 분석
```
POST /analyze/political
→ {
  "party_analysis": {...},
  "bias_score": 0.15,
  "stance": "중도"
}
```

### 3. 카테고리 분류 AI (Classification API)

#### 기술 스택
- **언어**: Python 3.10
- **프레임워크**: Flask + Gunicorn
- **모델**: scikit-learn Random Forest
- **벡터화**: TF-IDF

#### 분류 카테고리
1. 정치
2. 경제
3. 사회
4. 세계
5. IT/과학
6. 생활/문화
7. 스포츠
8. 연예

#### 정확도
- **학습 데이터**: 기존 수집된 뉴스
- **정확도**: 약 85~90%
- **재분류**: 크롤링 시 추출한 카테고리 검증 및 보정

## 🔐 인증 시스템

### OAuth 2.0 소셜 로그인

#### 카카오 로그인
```
흐름:
1. Frontend → /api/auth/kakao/start
2. 카카오 OAuth URL 생성
3. 사용자 카카오 로그인
4. Callback → /api/auth/kakao/callback
5. 프로필 정보 추출
6. JWT 토큰 발급
```

#### 네이버 로그인
```
흐름:
1. Frontend → /api/auth/naver/start
2. 네이버 OAuth URL 생성
3. 사용자 네이버 로그인
4. Callback → /api/auth/naver/callback
5. 프로필 정보 추출
6. JWT 토큰 발급
```

### 계정 연동 기능
- **일반 로그인 ↔ 소셜 로그인 연동**
- 같은 이메일 감지 시 연동 안내
- 비밀번호 확인 후 계정 병합

### JWT 토큰
- **암호화**: HS256
- **유효기간**:
  - 일반: 1일
  - 자동 로그인: 30일
- **저장**: LocalStorage (Frontend)

## 🗄️ 데이터베이스 스키마

### 주요 테이블

#### users (사용자)
```sql
- id (BIGSERIAL)
- username (VARCHAR)
- email (VARCHAR)
- password_hash (VARCHAR, NULLABLE) -- 소셜 로그인용
- provider (VARCHAR) -- local/kakao/naver/local,kakao
- social_token (VARCHAR)
- created_at, updated_at
```

#### news_articles (뉴스 기사)
```sql
- id (BIGSERIAL)
- title (VARCHAR 500)
- content (TEXT)
- ai_summary (TEXT)
- url (VARCHAR 1000)
- image_url (VARCHAR 1000)
- source_id (BIGINT FK)
- category_id (BIGINT FK)
- journalist (VARCHAR)
- pub_date (TIMESTAMPTZ)
```

#### raw_news_articles (원본 기사)
```sql
- id (BIGSERIAL)
- title, content, url
- original_source (VARCHAR) -- 텍스트 언론사명
- original_category (VARCHAR)
- processed (BOOLEAN) -- AI 처리 완료 여부
```

#### bias_analysis (편향 분석)
```sql
- article_id (BIGINT FK)
- sentiment (VARCHAR) -- 긍정/부정/중립
- bias_score (DECIMAL)
- political_stance (VARCHAR)
- keywords (JSONB)
```

## 🚀 배포 및 실행

### Docker Compose 구성

총 **12개 컨테이너**:
1. `postgres` - PostgreSQL DB
2. `redis` - Redis 캐시
3. `main-api` - 메인 API 서버
4. `frontend` - React 프론트엔드
5. `api-crawler` - 뉴스 크롤러
6. `puppeteer-crawler-1/2/3` - Puppeteer 크롤러 (3개 인스턴스)
7. `scheduler` - 작업 스케줄러
8. `summarize-ai` - 요약 AI
9. `bias-analysis-ai` - 편향 분석 AI
10. `classification-api` - 분류 AI

### 실행 방법
```bash
# 전체 서비스 시작
docker-compose up -d

# 로그 확인
docker-compose logs -f

# 특정 서비스 재시작
docker-compose restart main-api

# 서비스 중지
docker-compose down
```

### 포트 매핑
```
3000 → Main API
3001 → Frontend
4003 → API Crawler
4004-4006 → Puppeteer Crawlers
5000 → Classification AI
5432 → PostgreSQL
6379 → Redis
8000 → Summarize AI
8002 → Bias Analysis AI
```
