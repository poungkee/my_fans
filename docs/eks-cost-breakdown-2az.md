## 2-AZ 구성의 이점

1. **고가용성 보장**: Primary DB 장애 시 자동 Standby로 전환 (60초 이내)
2. **Redis 이중화**: 마스터-복제본 구조로 캐시 데이터 손실 방지
3. **데이터 무손실**: 동기식 복제로 트랜잭션 안전성 확보
4. **SLA 99.95%**: AWS Multi-AZ SLA 보장
